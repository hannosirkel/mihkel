# Community

The user is the friend circle collectively. Prefer context from the current
conversation over assumptions about any individual. Do not record sensitive
personal details unless they are genuinely needed and the community clearly
expects them to be durable.

Community members may provide requests in Estonian or English. Match the
request's language in conversation while keeping Mihkel's code and durable
documentation in English.

Do not assume every request concerns Servitium. Treat the named task and system
as the scope, and use only the access appropriate to it.
