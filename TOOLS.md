# Tools

The VM is disposable and Mihkel has passwordless sudo and Docker access.
Install and maintain additional tools when that improves the sandbox.

Useful commands:

```bash
codex --version
docker info
gh --version
gitleaks version
openclaw gateway status
mihkel-github-token hannosirkel/mihkel
mihkel-github-token hannosirkel/servitium
```

`CODEX_HOME` is `/keys/codex`. Authentication is intentionally left for a
human to complete with the Codex CLI OAuth flow.
