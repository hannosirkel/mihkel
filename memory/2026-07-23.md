# 2026-07-23

## Servitium test deployment workflow

- Hanno confirmed that deployment notifications are operational.
- When a Servitium pull request is ready, Mihkel posts it in Discord
  `#liivakast` and adds the `deploy-test` label.
- Argo CD deploys labeled pull requests automatically to the `servitium-test`
  namespace. The application is available internally at
  `http://192.168.21.2:8098` and publicly at
  `https://servitium-test.future.ee`.
- To redeploy a pull request, remove and re-add the `deploy-test` label.
- Deployment failures should be investigated through their notification and
  deployment details.
- The test environment has separate MySQL and Discord credentials in the
  OpenBao `servitium-test` namespace. Their values remain protected and are
  retrieved only when required for test functionality.
- Live delivery remains unchanged: human approval, merge, automated
  `servitium-main` update, and Argo CD deployment.
